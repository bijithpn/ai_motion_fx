# ai_motion_fx example

A small app that shows every widget in the `ai_motion_fx` package with live
controls, so you can try an option and see what it does before putting it in
your own code.

```bash
cd example
flutter run          # any device; try a phone and a desktop window
```

Tap the sun/moon button in the app bar to cycle the app theme (auto → light → dark). Each tab
also has its own `theme` chooser, in case you want a dark orb on a light page.

## What's in each tab

### ThinkingOrb

The nine animations, with controls for state, theme, colour palette, size,
speed, pause, reduced motion and a custom semantic label. Below the preview:

- **All states**: every animation side by side.
- **Shaping**: every held shape.
- **Two tuned sizes**: the 64 px and 20 px designs next to each other, so you
  can see they're separate designs and not one scaled copy.

### Image Generation (`ThinkingImageReveal`)

The pixel-mosaic loader that clears to reveal a picture.

- Pick a **preset**: `pixels-organic`, `pixels-mechanic` or `sweep-gradient`.
- **autoReveal** loops through the images on its own. Turn it off and the
  loader waits until you press **Replay**, which is how you'd use it for a real
  "generating…" state.
- **Next image** skips ahead; **paused** freezes it.
- The **images** chooser includes a *Broken URL* option, so you can see that a
  picture that never loads just keeps the loader churning, with no crash.
- The three pictures are in `assets/`, so everything works offline.

The bottom panel shows all three presets at once.

### Voice Glow (`ThinkingVoiceGlow`)

A mock chat input with the sound-reactive glow on its bottom edge.

- There's no real microphone here. **Simulate a live mic level** feeds in a
  made-up level that rises and falls like speech, with small pauses. Turn it
  off to set the `level` by hand with a slider.
- **processing** gathers the glow into a travelling beam.
- **Input chain** has `sensitivity`, `threshold`, `attack` and `release`.
  Dragging `release` up is the quickest way to feel what it does.
- **Shape** has `reach`, `spread`, `flow` and `idle`.
- `type` switches between the chat box, the small recording pill and the
  bottom-of-phone geometry. The bottom panel shows all three.

### Beam (`ThinkingBeam`)

The comet of colour around a card's border.

- Five **sizes** (`md`, `sm`, `line`, `pulse-inner`, `pulse-outside`) and
  eight **colour variants**.
- `strength`, `speed` and **lap time** control how it moves; the child's width,
  height and corner radius sliders show it follows any shape.
- **In context** puts it on a "Searching…" chip with an orb in it and on a chat
  input.

## Where to look in the code

Everything is in `lib/main.dart`: one `StatefulWidget` per tab, plus a few
small helpers (`Stage`, `Panel`, `Num`, `Choice`, `toggle`) that build the
preview card and the controls. If you want to copy a pattern, each tab's
`build` method is a good starting point; they're written to be read.

The sample pictures were generated by `tool/gen_art_test.dart` in the package
root, if you ever want different ones.
